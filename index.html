🧩 Marketplace de Plugins

Ecosistema estilo Acode: instale, ative e combine extensões. Tudo fica salvo no seu navegador.

⚙️ Configurações e Integrações

Chaves ficam só no seu navegador (localStorage). Nada é enviado a terceiros sem sua ação.

🧠 Modelos de IA (gratuitos)

Modelos sugeridos: google/gemini-2.0-flash-exp:free, meta-llama/llama-3.1-8b-instruct:free, mistralai/mistral-7b-instruct:free (OpenRouter), llama-3.1-nemotron-70b (NVIDIA), gemini-2.0-flash (Gemini), abab6.5s-chat (MiniMax).

💬 WhatsApp Bridge

O agente envia e recebe mensagens pelo webhook. Com o Base44 Superagent você cria o bridge real; com o n8n você conecta a API oficial do WhatsApp Business. O plugin "WhatsApp Bridge" do marketplace usa esta configuração.

🔄 Automação (n8n) e Dados (Supabase / Firebase)

n8n: cada comando /n8n no chat dispara o fluxo. Supabase: o plugin "Memória Supabase" salva o histórico da conversa. Firebase: sincronização multi-dispositivo (roadmap do app).
